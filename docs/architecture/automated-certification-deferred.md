# Automated BKE artifact certification is intentionally deferred

The active commercial release flow is deliberately limited to external-object
registration, exact artifact verification (SHA-256 and byte size), human review,
human approval, and licensed distribution.

Commissioning tables and historical technical evidence remain for audit history
and possible later reuse, but artifact registration does not create commissioning
runs and the scheduler does not process certification work. SBOM, dependency
analysis, migration assessment, BKE provenance, the commissioning state machine,
and analyzer frameworks may be restored as a future architecture; none is an
active release requirement today.
